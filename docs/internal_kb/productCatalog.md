# 产品线说明与分类

## 1. 产品线总览
- AI Tools：人工智能工具套件，属于 AI 类，2022 年上市。
- Cloud Services：云服务，属于 Cloud 类，2019 年上市。
- Data Platform：数据平台，属于 Data 类，2021 年上市。
- Security Suite：安全套件，属于 Security 类，2020 年上市。

## 2. 提成分类
- 基础产品包括 AI Tools 与 Security Suite。
- 战略产品包括 Data Platform 与 Cloud Services。
- 产品的提成分类每年复核一次，调整需财务与销售双方确认。

## 3. 产品生命周期
- 上市未满 2 年的产品视为新品，享受新品推广预算。
- 连续 4 个季度销售额下滑超过 20% 的产品进入退市评估。
