# 销售区域划分与职责说明

## 1. 区域划分
- 公司销售区域分为 East、West、South、North 四个大区。
- 每个大区设一名区域销售经理，负责区域业绩与审批。
- 大区划分以客户注册地为准，跨区订单归属签约销售所在大区。

## 2. 区域经理职责
- 审批本区域低额度退款及普通、重点客户的折扣申请。
- 每月 5 日前提交上月区域销售复盘报告。
- 负责区域内销售人员的季度业绩考核。

## 3. 业绩考核指标
- 季度考核以区域总销售额（revenue）完成率为主，权重 70%。
- 辅助指标为新客户数量与回款及时率，权重分别为 20% 和 10%。
- 完成率低于 80% 的区域，经理需提交改进计划。
