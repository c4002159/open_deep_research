# 客户退款与售后处理规范

## 1. 退款适用条件
- 订单交付后 30 天内，客户可对未激活的产品许可申请全额退款。
- 已激活的订阅类产品（AI Tools、Cloud Services）仅可申请按剩余月份折算的部分退款。
- 因公司原因导致服务中断超过 72 小时的订单，不受 30 天期限限制，可全额退款。

## 2. 退款审批权限
- 退款金额（revenue）低于 5,000 元：区域销售经理审批即可。
- 退款金额 5,000 至 50,000 元：需区域销售经理与财务经理双签。
- 退款金额超过 50,000 元：必须由财务总监审批，并在 3 个工作日内完成。

## 3. 退款与提成的联动
- 订单发生退款时，对应销售人员的提成在下一季度等额扣回。
- 部分退款按退款占订单金额的比例扣回提成。
- 退款申请被驳回的，不影响已计提的提成。

## 4. 售后响应时效
- 一级故障（服务不可用）：15 分钟内响应，4 小时内给出临时方案。
- 二级故障（功能降级）：2 小时内响应，1 个工作日内修复。
- 咨询类问题：1 个工作日内回复。
