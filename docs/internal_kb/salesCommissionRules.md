# 2024年度销售提成与奖金发放规范

## 1. 适用范围
本规范适用于公司全体直接面向客户的销售人员（Sales Representative）。

## 2. 提成比例计算
- 基础产品（如 AI Tools, Security Suite）：按单笔订单净销售额（revenue）的 5% 计提。
- 战略产品（如 Data Platform, Cloud Services）：按单笔订单净销售额（revenue）的 8% 计提。
- 若单笔订单 sales units > 100，则该笔订单额外享受 2% 的大单激励。

## 3. 发放周期
提成每季度核算一次，并在次月随工资一同发放。若订单发生退款，需在下个季度的提成中进行等额扣除。
