# 销售报表指标口径定义

## 1. 销售额口径
- 销售额统一指 revenue 字段，为单笔订单的净销售额，已扣除折扣，不含税。
- 汇总销售额按订单日期（date）归属期间，不按回款日期。
- 退款订单的销售额在退款发生期间冲减，不回溯修改原期间数据。

## 2. 销量口径
- 销量统一指 units 字段，表示订单中的商品件数。
- 同一订单拆分为多条记录时，销量按记录累加，不去重。

## 3. 客单价与均价
- 客单价 = 期间总销售额 / 期间订单数，保留 2 位小数。
- 产品线平均每笔销售额按产品线分组后对 revenue 求平均。
- 均价类指标一律先聚合再相除，禁止对已求平均的结果再次求平均。

## 4. 同比与环比
- 环比指相邻自然季度对比，同比指与上年同季度对比。
- 增长率 = (本期 - 上期) / 上期，上期为 0 时显示为"无可比数据"。
- 季度划分：一季度 1-3 月，二季度 4-6 月，三季度 7-9 月，四季度 10-12 月。
