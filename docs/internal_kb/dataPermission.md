# 数据访问权限与脱敏规范

## 1. 数据分级
- 公开级：产品介绍、公开报价，所有员工可见。
- 内部级：区域销量汇总、产品线销售额汇总，需要登录内网账号。
- 机密级：客户明细、单笔订单金额、提成明细，仅限业务相关岗位申请后访问。

## 2. 数据库访问原则
- 数据分析类查询一律使用只读账号，禁止在生产库执行 INSERT、UPDATE、DELETE 和 DDL。
- 单次查询返回行数上限为 200 行，需要更多数据时必须走数据导出流程并留痕。
- 查询需要先确认表结构，禁止猜测字段名后直接执行。

## 3. 敏感字段脱敏
- 客户手机号展示时保留前 3 位和后 4 位，中间以星号替代。
- 客户全称在对外报告中统一替换为客户编号。
- 员工薪资与提成明细不得出现在任何对外分享的报告中。

## 4. 违规处理
- 首次违规：书面警告并回收数据访问权限 30 天。
- 导致数据外泄的：按公司信息安全制度处理，情节严重的移交法务。
