# 客户分级与折扣审批规范

## 1. 客户分级标准
- 战略客户：年度累计销售额超过 500,000 元。
- 重点客户：年度累计销售额在 100,000 至 500,000 元之间。
- 普通客户：年度累计销售额低于 100,000 元。
- 客户等级每年 1 月 1 日统一重新评定一次。

## 2. 折扣权限
- 普通客户：销售人员可直接给予不超过 5% 的折扣。
- 重点客户：折扣不超过 10%，需区域销售经理审批。
- 战略客户：折扣不超过 15%，需销售副总裁审批。
- 任何超出上述上限的折扣，必须提交总经理办公会专项审批。

## 3. 大单特殊政策
- 单笔订单 units 超过 100 的订单视为大单，除享受大单激励外，可申请额外 2% 的价格补贴。
- 大单必须在合同签署前 3 个工作日提交评审。
